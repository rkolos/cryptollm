# Инструкции по установке зависимостей

## Стандартная установка

```bash
npm install
```

Все зависимости проекта установятся автоматически без необходимости компиляции нативных модулей.

## Технический анализ

Проект использует библиотеку `technicalindicators` для всех расчетов технических индикаторов:
- Базовый пакет: EMA, RSI, MACD, Bollinger Bands, Key Levels
- Расширенный пакет: ADX, ATR, OBV, VWAP, Stochastic

Все необходимые индикаторы доступны в `technicalindicators`, которая написана на чистом JavaScript и не требует компиляции.
