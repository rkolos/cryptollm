# Инструкция по настройке Binance Testnet (Песочница)

## Что такое Binance Testnet?

Binance Testnet — это тестовая среда Binance, где вы можете тестировать торговые стратегии без риска потери реальных средств. Все операции выполняются с виртуальными деньгами.

## Шаг 1: Регистрация на Binance Testnet

1. **Перейдите на сайт Binance Testnet:**
   - Откройте в браузере: https://testnet.binance.vision/

2. **Войдите через GitHub:**
   - Нажмите кнопку "Log In with GitHub"
   - Авторизуйтесь через ваш GitHub аккаунт
   - Если у вас нет GitHub аккаунта, создайте его на https://github.com

3. **После входа вы увидите:**
   - Виртуальный баланс (тестовые средства)
   - Возможность создания API ключей

## Шаг 2: Создание API ключей

1. **Перейдите в раздел API Management:**
   - В верхнем меню найдите раздел "API Management" или "API Keys"
   - Или перейдите напрямую: https://testnet.binance.vision/en/myAccount

2. **Создайте новый API ключ:**
   - Нажмите кнопку "Generate HMAC_SHA256 Key" или "Create API Key"
   - Введите название для ключа (например, "MLforex Bot")
   - Подтвердите создание

3. **Сохраните ключи:**
   - **API Key** — публичный ключ (например: `abc123...`)
   - **Secret Key** — секретный ключ (например: `xyz789...`)
   - ⚠️ **ВАЖНО:** Secret Key показывается только один раз! Сохраните его немедленно.

## Шаг 3: Обновление .env файла

Откройте файл `.env` в корне проекта и обновите следующие строки:

```env
# Режим работы (уже должен быть установлен)
APP_MODE=testnet

# Замените на ваши ключи от Binance Testnet
BINANCE_API_KEY=ваш_api_key_от_testnet
BINANCE_API_SECRET=ваш_secret_key_от_testnet
```

**Пример:**
```env
APP_MODE=testnet
BINANCE_API_KEY=abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
BINANCE_API_SECRET=xyz789uvw456rst123opq890lmn567ijk234ghi901def678abc
```

## Шаг 4: Проверка подключения

После обновления ключей проверьте подключение:

```bash
npm run test:testnet
```

Скрипт проверит:
- ✅ Подключение к Binance Testnet
- ✅ Валидность API ключей
- ✅ Получение баланса
- ✅ Получение рыночных данных

Если все проверки пройдены успешно, вы увидите:
```
✅ Все проверки пройдены успешно!
🎉 Binance Testnet подключен и работает корректно.
```

## Шаг 5: Запуск проекта

После успешной проверки подключения запустите проект:

```bash
npm run dev
# или
npm run build && npm start
```

В логах вы увидите:
```
⚠️  Binance Testnet mode enabled.
```

## Важные замечания

1. **Не путайте ключи:**
   - Ключи от основного Binance аккаунта ≠ ключи от Testnet
   - Убедитесь, что используете ключи именно от testnet.binance.vision

2. **Баланс:**
   - В Testnet вам автоматически выдается виртуальный баланс
   - Все операции выполняются с виртуальными средствами
   - Реальный баланс не затрагивается

3. **API Endpoints:**
   - Код автоматически использует правильные endpoints при `APP_MODE=testnet`
   - Никаких дополнительных настроек не требуется

4. **Безопасность:**
   - Не коммитьте `.env` файл в Git (он уже в .gitignore)
   - Не делитесь своими API ключами

## Режимы работы

В проекте доступны три режима:

- **`testnet`** — подключение к Binance Testnet (песочница)
- **`dry_run`** — симуляция без реальных запросов к бирже
- **`production`** — реальная торговля (требует ключи от основного аккаунта)

## Проблемы и решения

### Ошибка 401/403 при проверке подключения
- **Причина:** Неверные API ключи или ключи от основного аккаунта
- **Решение:** Убедитесь, что используете ключи от testnet.binance.vision

### Скрипт не находит API ключи
- **Причина:** Ключи не установлены в .env
- **Решение:** Проверьте наличие `BINANCE_API_KEY` и `BINANCE_API_SECRET` в .env

### APP_MODE не testnet
- **Причина:** В .env установлен другой режим
- **Решение:** Установите `APP_MODE=testnet` в .env
