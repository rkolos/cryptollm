# Важное примечание о tulind

Библиотека `tulind` указана в `package.json`, но требует предварительной установки C-библиотеки `ta-lib`.

## Если tulind не установился автоматически

`npm install` может завершиться с ошибкой для `tulind`. Это нормально, если:
1. `ta-lib` не установлена в системе
2. Не принята лицензия Xcode (macOS)

## Решение

Следуйте инструкциям в `INSTALL.md` для установки `ta-lib`, затем выполните:

```bash
npm install tulind
```

## Альтернатива

Проект может работать с использованием только `technicalindicators`. Если не планируете использовать `tulind`, удалите его из `package.json`:

```bash
npm uninstall tulind
```

## Проверка работы без tulind

Проект успешно компилируется и работает без `tulind`. Типы для `tulind` уже определены в `src/types/tulind.d.ts` для будущего использования.
